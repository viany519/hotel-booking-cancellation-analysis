# Hotel Booking Cancellation Analysis

This project explores hotel reservation data to identify factors associated with booking cancellations through Exploratory Data Analysis (EDA).

## Project Overview
Hotel booking cancellations can affect hotel revenue, operational planning, and room availability. This project analyzes booking data to understand customer and reservation characteristics related to cancellations.

## Objectives
The analysis focuses on several questions:

- Does lead time affect cancellation rate?
- Do family travelers cancel less frequently?
- Does room price influence cancellation?
- Which market segment has the highest cancellation rate?
- Are guests with special requests less likely to cancel?

## Dataset
The dataset contains hotel reservation information including:

- Lead time
- Room type
- Market segment
- Average room price
- Special requests
- Booking status

## Key Findings
The analysis shows that several booking characteristics are associated with cancellation behavior, including lead time, market segment, room price, and number of special requests.
